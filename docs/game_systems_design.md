# 深漂生存喜剧 - 系统设计文档

> 2026-05-21 联合设计确认
> 核心理念：数值驱动的都市生存模拟，玩家选择塑造人生
> 参考标杆：冰汽时代（Frostpunk）——每个选择都有代价，没有完美答案

---

## 一、核心哲学

### 这个游戏是什么

**数值游戏 + 生活模拟**。不是剧本游戏，不是路线游戏。

玩家的体验来自"每一步都在牺牲别的东西"：
- 去夜校上课 → 花钱花精力 → 这周干不了别的 → 年龄还在涨
- 去健身房 → 颜值涨了 → 但学识没涨 → 门槛跟不上
- 去酒吧 → 情商涨了 → 但花了500块 → 花呗又多了一笔
- 加班赚钱 → 精力耗尽 → 什么都做不了 → 属性停滞

**玩家永远在还机会的债。**

### 三个核心原则

1. **Game Over是sanity归零，不是事件失败。** 事件失败只扣sanity，sanity有余量就继续。
2. **NPC触发基于数值，不是年龄。** 你做了什么选择→你变成什么样的人→你遇到什么样的人。年龄只做最低门槛。
3. **删除就是删除。** 删了小雅没有替代品。友谊不可替代，选择不可逆。

## 二、数值平衡框架

### 起始数值

```
年龄：23（终点33，来深圳10年）
金钱：3000
精力：100 / max 100
情绪：100 / max 100
颜值：10
学识：10
情商：10
```

### 工资体系

```
job_level 0 · 初级行政：  月薪 4000（周薪 1000）
job_level 1 · 新媒体运营：月薪 8000（周薪 2000）
job_level 2 · 大客户经理：月薪 15000（周薪 3750）
```

### 生存压力测试

**最低生存**（job_level=0，城中村，挂逼套餐）：

```
月收入：  +4000
月房租：  -1500
月伙食：  -300
月净剩：  +2200
春节年扣：-5000（摊月 -417）
实际月剩：+1783
```

结论：月薪4000，每月只能投资自己一次。剩下的时间吃饭上班睡觉。

**升级后**（job_level=1，城中村，标配）：

```
月收入：  +8000
月净剩：  +5700
实际月剩：+5283
```

可以每周做一次活动，偶尔买护肤，偶尔上课。

**高薪**（job_level=2，精装公寓，标配）：

```
月收入：  +15000
月净剩：  +10200
实际月剩：+9783
```

有积蓄能力，但可能到28-30岁才能达到。

### 活动成本收益

| 活动 | 精力 | 金钱 | 收益 |
|------|------|------|------|
| 图书馆 | -20 | 0 | +2学识 +5情绪 |
| 健身房 | -45 | -200 | +2颜值 +5情绪 max_energy+1 |
| 酒吧 | -20 | -500 | +2情商 +25情绪 |
| 宅家 | -10 | 0 | +20情绪 |
| 夜校 | -50 | -1000 | +1学分 |
| 护肤品 | 0 | -800 | +5颜值 +5情绪 |
| 医美 | 0 | -6000 | +25颜值 +20情绪 |
| 高级医美 | 0 | -20000 | +50颜值 +30情绪 -10情商 |

### 属性成长时间

```
学识 10→50：图书馆20次 = 20周 = 5个月（免费）
情商 10→50：酒吧20次 = 20周 = 5个月（花费10000金）
颜值 10→50：健身房20次 = 20周 = 5个月（花费4000金）
或 医美捷径：6000金 + 护肤4次3200金 = 快但贵
夜校12学分：12次 = 12周 = 3个月（花费12000金）
```

**核心发现：情商最贵（每点500金），学识免费。没钱=情商上不去。**

### 精力经济

```
每周精力分配（上限100）：

上班(摸鱼)后剩85：可做夜校(50)+一件轻量事
上班(正常)后剩70：可做健身房(45)或 图书馆+酒吧
上班(加班)后剩50：只能做一件事

关键：加班 = 这周只能做一件事
短期赚钱 vs 长期投资自己
```

### 情绪压力曲线

```
最惨月流失：-50（挂逼+加班+城中村事件+无社交）
满sanity(100) → 2个月归零

正常月净增：+25（标配伙食+每周去一次酒吧+偶尔加班）

sanity平衡点：标配伙食+偶尔社交+偶尔加班 → 缓慢增长
春节失败扣60 → 需要2-3个月恢复 → 这2-3个月又有压力
```

## 三、春节BOSS战系统

### 基本规则

- 每年一次，自动触发
- 多轮对话，每轮一个亲戚攻击一个话题
- 玩家根据数值选择回应（数值不够的选项灰色不可选）
- 每轮通过：sanity不变或+5；失败：sanity扣5~25
- 所有轮次打完，总sanity扣到0才game over
- 年份越高，轮次越多，检定越难

### 每年难度

| 年龄 | 轮数 | 话题池 | 难度 |
|------|------|-------|------|
| 24 | 3 | 事业+生活 | 简单 |
| 25 | 3 | 事业+婚恋(初现) | 简单 |
| 26 | 4 | 事业+婚恋+比较 | 中等 |
| 27 | 5 | 全部 | 较难 |
| 28 | 4-5 | 特殊年：妈妈来深圳 | 场景不同 |
| 29 | 5 | 全部+年龄焦虑 | 难 |
| 30 | 6 | 全部 | 很难，需要双属性 |
| 31 | 6 | 全部 | 极难 |
| 32 | 7 | 全部 | 最高难度 |
| 33 | 不打BOSS | 终局判定 | 10年总成绩 |

### 话题池

```
【事业类】
· "在大城市做什么工作啊？" → job_level检定
· "工资多少？" → money检定
· "你那个公司靠谱吗？" → intellect检定

【婚恋类】
· "有对象没？" → eq检定 或 有NPC flag
· "别挑了，差不多就行了" → eq >= 50
· "你看你表妹，孩子都两岁了" → sanity直接-10，无法防守
· "我给你介绍一个" → eq >= 40婉拒 / 否则被迫接受

【比较类】
· "你表哥在老家买房了" → money >= 80000反击
· "你同学都结婚了" → sanity -5固定伤害
· "你看你堂姐，嫁得多好" → eq >= 50反驳

【亲情绑架类】
· "你妈天天失眠念叨你" → sanity -8固定
· "你爸头发都白了" → sanity -10固定
· "你是我们家唯一的希望" → intellect >= 50可化解

【温暖类（低概率，给玩家喘息）】
· "累了就回家，家里有饭" → sanity +10（但触发回家选项）
· 妈偷偷塞了5000块 → money +5000, sanity +15
```

### 特殊年：28岁妈妈来深圳

根据前4年表现，妈妈来意不同：
- 前几年基本pass：来看你过得好不好
- 前几年经常fail：接你回去

检定住房、冰箱、花呗账单。最后妈妈说"跟我回去"→ 玩家需要用job_level/money/eq说服她。

## 四、触发条件矩阵

### 六个维度

```
A. 核心数值：money, energy, sanity, charm, intellect, eq
B. 生活状态：job_level, degree, housing_level, huabei_debt, invest_*
C. NPC状态：每个NPC的affection, flags, 是否删除/拉黑
D. 行为记录：连续加班、连续吃土、上课次数、去酒吧次数、...
E. 年龄时间：age（只做最低门槛，不做触发条件）
F. 缺失状态：没有朋友、没有恋人、没有学历、工作差...
```

### "你有X但没有Y"型触发

| 状态 | 触发 | 效果 |
|------|------|------|
| charm>=35 且 intellect<20 | 酒吧搭讪成功但聊不下去 | 尴尬，sanity-8 |
| charm>=35 且 eq<25 | 被搭讪但看不清意图 | 容易被骗 |
| money>=50000 且 eq<30 | 同事借钱 | 借/不借都有后果 |
| intellect>=50 且 charm<15 | 工作强但存在感低 | 被抢功劳 |
| job_level>=2 且 sanity<30 | 事业成功但身心俱疲 | 深夜在办公室哭 |
| degree==1 且 age>=28 | 学历拿到但青春没了 | 同龄人已有积蓄 |

### "你一直在做X"型触发

| 行为模式 | 触发 |
|---------|------|
| 连续图书馆>=8次 从未去酒吧 | "书呆子"标签 |
| 连续酒吧>=5次 没去过图书馆 | "玩咖"标签 |
| 连续上课>=6次 无缺席 | "学霸"flag，王老师推荐好工作 |
| 连续吃挂逼套餐>=3次 | 身体警告（已有） |
| 连续加班>=3次 | 疲惫警告（已有） |
| 连续宅家>=4次 | 小雅问"你还好吗" / 如小雅被删则无人关心 |
| 每月刷花呗从未还清 | "月光族"标签 |
| 从未刷花呗 money>=30000 | "理财达人"flag |

### "你缺少X"型触发

| 缺失状态 | 触发 |
|---------|------|
| 无任何NPC 且 age>=26 | 深夜独处日记，sanity-10 |
| 小雅被删除 无其他女性NPC | 社交真空，sanity恢复更慢 |
| degree==0 且 age>=27 | 学历焦虑，跳槽跳不了 |
| housing_level==0 且 age>=28 且 money>=20000 | 搬家念头 |
| 无男友 且 age>=29 且 sanity>=60 | 单身自由事件 |
| 无男友 且 age>=29 且 sanity<40 | 单身孤独事件 |

### "NPC行为反推"型触发

| NPC状态 | 触发 |
|--------|------|
| 小雅好感>=60 且 有男友 | 约你见面带男友来 |
| 小雅好感<=10 | 发来"我们是不是不太合适做朋友了" |
| 沈逸被拉黑 且 eq>=60 | 朋友圈看到他给别的女生留同样的言 |
| 家庭群affection>=70 且 money>=80000 | 爸打电话关心你 |
| 家庭群affection<=20 | 群里不再有人@你 |

### "里程碑后果"型触发

| 里程碑 | 后续触发 |
|--------|---------|
| 拿到本科 | 同学反应（正+反） |
| 跳槽成功 | 前同事微信 + 新公司试用期压力 |
| 第一次月薪过万 | 日记自豪 sanity+15 |
| 第一次存款过十万 | 银行推销房贷 |
| 第一次存款过三十万 | "您现在够首付了" |
| 做了医美 | 不同人不同反应 |
| 删除了小雅 | 一个月后想找人说话发现没有人了 |
| 被沈逸骗后识破 | 获得"鉴渣能力"flag |
| 被沈逸骗后未识破 | "信任危机"，eq检定+10但sanity上限-10 |

| 死法 | 触发条件 |
|------|---------|
| 福报的代价 | 连续加班>=5周（已有） |
| 恩格尔系数0.01 | 连续吃挂逼>=5周（已有） |
| 情绪崩溃 | sanity归零（已有） |
| 破产绝路 | 月末money<0（已有） |
| 负债累累 | 花呗最低还款付不起（已有） |
| 春节破产 | 春节后money<0（已有） |

| 结局 | 条件 | 概述 |

## 六、职场微事件系统

### 设计

每周上班时，60%概率触发0-1个微事件。
给+1~+2属性，积少成多。
文字像朋友圈吐槽，不是正经叙事。
有好的也有坏的（坏的给经验）。
有些根据玩家阶段触发。

### 数值影响

10年480周 × 60%触发率 ≈ 288次微事件。
每次平均+1属性 → 每项额外+30~50左右。
**这个数字要在数值平衡中扣除，不能因此变得不平衡。**

### 分类

- **情商类**：甩锅回去、读懂老板潜台词、电梯社交、安慰同事...
- **学识类**：午休刷行业文章、学会Excel新函数、三天速成新软件...
- **颜值类**：被问口红色号、穿新衣服被夸、发现穿衣显瘦的真理...
- **精力类**：发现公司天台、找到省10分钟的通勤路线...
- **情绪类**：发工资了、老板没来、外卖小哥说辛苦了...
- **负面类**：方案被否定、被同事抢功、当众被骂（扣情绪但加学识/情商）
- **阶段类**：入职第一天、转正后、升职后、加班狂、月薪过万、30岁...

### 实现

```
数据格式：JSON数组
每条事件：text, stat_changes, conditions(可选), tags, weight
触发逻辑：满足conditions → 按weight随机 → 最近3周不重复
```

## 七、连锁反应边界

### 链条1：花呗螺旋

```
月光 → 花呗涨 → 最低还款吃工资 → 钱不够 → 吃挂逼 → 精力低
→ 加班累 → sanity降 → 深夜失眠 → 冲动消费 → 循环
```

安全阀：
- 欠款5000：纯提示
- 欠款10000：小剧场，让玩家意识到严重性
- **欠款20000：给出口（找小雅借/找父母要/卖投资/继续扛）**
- 欠款30000：催收到公司
- 欠款50000：人造名媛风险
- 欠款80000：老赖结局（不可逆点）

### 链条2：情绪螺旋

```
坏事 → sanity降 → 负面事件概率升 → sanity继续降 → 循环
```

安全阀（sanity越低自救越多）：
- sanity 50-69：小雅/妈关心你（可忽略）
- sanity 30-49：自救更频繁（小雅约你出来、妈寄特产、免费心理热线）
- sanity 10-29：强制自救（天台小剧场，妈打电话说废话），2周保护期
- sanity 0-9：最后一次选择（去看医生=活着结束 / 不去=game over）

例外：如果玩家拒绝所有帮助3次以上，安全网逐渐消失。不是系统不帮，是你拒绝了所有能帮你的人。

### 链条3：社交孤立

**删了就是删了。没有替代品。没有替补社交入口。**

删小雅的后果：
- 没有人可以倾诉
- 没有人可以借钱
- 遇到渣男没有人提醒
- 宅家sanity恢复减半
- 但图书馆sanity恢复增加（书不会辜负你）

删除是永久的。这是现实。

### 链条4：加班螺旋

```
加班 → 精力耗尽 → 属性停滞 → 年龄涨门槛涨 → 跟不上 → 继续加班
```

不打断，只警告：连续3周提醒、连续4周NPC关心。玩家自己选。

### 链条5：属性偏科

```
颜值高 → 搭讪触发 → 但学识不够聊不下去 → 继续投资颜值 → 锁死在花瓶路线
```

不打断，只提示。charm>=30且intellect<20时触发小剧场让玩家意识到。

### 总结

| 链条 | 处理 | 理由 |
|------|------|------|
| 花呗 | 关键节点给出口 | 纯经济锁死没有游戏性 |
| 情绪 | sanity越低自救越多 | 直接关联game over |
| 社交 | 不打断 | 删了就是删了 |
| 加班 | 只警告 | 玩家主动行为 |
| 偏科 | 只提示 | 策略选择的后果 |

## 八、NPC系统

### NPC设计原则

1. NPC从真实的女性体验中长出来，不是从游戏设计理论中捏出来
2. NPC触发基于数值门槛（你做了什么选择→遇到什么人），年龄只做最低门槛
3. NPC可删除，删除不可逆
4. NPC有自己的生活线（小雅会结婚、阿强会回老家）
5. NPC之间会交互（小雅评价你的男朋友、妈跟房东张姐聊天）

### 触发条件一览

| NPC | 触发条件 | 来源 |
|-----|---------|------|
| 小雅 | 无（游戏开始就在） | 发小 |
| 周姐/同事 | 无（上班就有） | 职场 |
| 阿强 | 无（家庭群推送） | 父母介绍 |

### NPC详细设计

#### 小雅（闺蜜/发小）

**背景**：同一个县城出来的，高中同班。你先来深圳，她半年后也来了。到深圳第一天你去车站接的。

**不需要邂逅触发。游戏开始时就在微信通讯录里。**

**功能**：
- 社交支撑（sanity恢复、倾诉）
- 社交压力（攀比、她的结婚进度）
- 紧急资源（可借钱，但好感会降）
- 有自己的人生线（谈恋爱→订婚→结婚→可能辞职带孩子）

**聊天类型**：
- 老乡型："今天看到有人卖我们那里的糍粑"
- 较劲型："我上个月工资终于到八千了"
- 真心型："你还记得我们高中说要一起在深圳买房吗"
- 她的麻烦："姐妹我被渣男了"/"我可能要离职了"

**借钱规则**：
- 首次借最多3000，好感-15
- 第二次最多2000，回复变慢，好感-20
- 第三次可能拒绝，好感-30
- 还钱恢复好感但不完全（裂痕永久）
- 借了不还3个月→小雅可能主动删你

**小雅的人生线**：
- 26-27岁：交了男朋友，话题开始变
- 28岁左右：订婚，份子钱800金
- 29岁左右：结婚，聊天频率降低
- 30岁后：偶尔说"你还好吗""我想你了"

**删除后果**：
- 7天后小剧场：想找人聊天发现不在了
- 你妈会打电话问"小雅妈说你把她删了？"
- 删的不只是好友，是跟老家/过去的最后一根线

#### 阿伟（城中村房东儿子）

**背景**：不明说潮汕人，但处处潮汕人的感觉。以家族为重，有点妈宝，传统观念。土土的但真心对女主好。家里有钱（收租）但没文化。

**触发**：housing_level==0（住城中村），随机触发。修水龙头认识。

**日常**：在城中村的日常里自然接触，不是"约会"是"碰面"。

**核心矛盾**：
- 前期：他实实在在对你好（免费修东西、送吃的、接送）
- 中期：见到他妈和家庭 → 传统/重男轻女/大家族规矩/祠堂
- 后期：他的好是真的，但他的世界可能让你窒息

**vs 林远的区别**：
- 阿伟：有钱（家里收租）但没文化，传统家庭是隐患
- 林远：有文化（小镇做题家）但钱一般，精神契合

#### 阿强（父母介绍的同乡男生）

**背景**：跟你一个县，初中毕业出来打工（做装修/送外卖），每个月给家里寄钱。老实、善良、喜欢你因为你是"老家出来的女孩子"。

**触发**：无门槛，家庭群推送微信。

**特征**：
- 聊天就死（"吃饭了吗""哦"）
- 但会做实在事（帮你搬家、借钱不求还）
- 最容易的感情线：不需要任何属性门槛
- 但他的终点是回老家 → 跟他在一起 = 离开深圳
- 跟林远不同：连供房能力都没有

**选择阿强 = 选择回老家。最容易的路，但也是最退的路。**

#### 沈逸（文艺渣男）

**已有完整设计**。15条日常+5里程碑+2线下约会+反杀系统+trap ending。不需要改动。

#### 陈默（高端局男性/经济控制型）

**背景**：有钱、有品味、出手大方。"我养你"=你要听我的。

**触发**：charm>=35 + 去酒吧 + 穿了宝淘衣服（消费flag）。

**核心矛盾线**：
- 甜蜜期(0-40)：请吃饭不看价格，送礼物不用你开口
- 控制期(40-70)：开始干涉你的社交圈/穿着/工作
- 决裂期(>=70)：分手 or 金丝雀结局

**检定**：eq>=50开始察觉，eq>=65能挣脱。

**与其他系统交互**：
- 小雅在→小雅会提醒"他控制欲太强"
- 花呗欠着→他说"我还"→你更离不开
- money>=50000→你有底气说"不"

#### 林远（普通好男人/小镇做题家）

**背景**：培训机构老师，月薪8000。不帅不有钱不浪漫，但靠谱。小镇做题家，靠大学一步步找工作，精神不匮乏。

**触发**：滑动交友(charm>=20) 或 相亲(春节失败触发)。

**核心矛盾**：你能不能在见识过沈逸的深情和陈默的富有之后，还看到他的好。

**关键设计**：
- 不需要属性门槛就能"得到"他
- 但需要 eq>=40 才能"看懂"他的好
- 他给你的是朴素的善意："吃了吗？"
- 不加利息借钱，不要感激，不拿来当筹码

#### 创二代（不可攻略的镜子NPC）

**背景**：有钱人家少爷。年轻、有教养、跟你聊得来。但家庭早就安排好了婚姻。

**触发**：job_level>=2 且 intellect>=40 且 eq>=40 且 money>=80000。

**功能**：不是选项，是一面镜子。让玩家看到阶层的墙。
"你用了十年从县城走到CBD。他生下来就在这里。你只是被允许参观的，不是被邀请留下的。"

#### 周姐/同事（职场NPC）

**触发**：上班就有。不需要邂逅。

**三种形态**：
- 吐槽搭子：一起骂甲方骂老板，sanity+3
- 竞争对手：争晋升，eq检定
- 塑料姐妹：根据你混得好不好决定态度

**男同事事件**：
- 正常型：一起加班骂甲方
- 油腻型：eq检定应对，处理不好sanity持续降
- 骚扰型（灰色地带）：团建总坐你旁边/下班后发消息，没有标准答案

#### 地铁搭讪（随机事件）

不是NPC，是随机事件。每年触发1-2次。
类型：健身房销售/搭讪/微商/偶尔正常。
价值：让玩家觉得"对，这就是我每天的生活"。

#### 房东张姐（功能NPC）

不是社交对象，是生活压力事件源。
- 涨租：eq检定谈判
- 突击检查：逼你续约或搬家
- 催租：月末经济紧张时
- 维修纠纷：自己修/忍着/换房

## 九、系统间连锁反应示例

### 连锁链1：学历提升路线

```
上夜校(1000金+50精力/次) → 钱不够 → 可能要花呗 → 花呗螺旋
→ 精力不够 → 去不了健身房 → 颜值不涨 → 社交受影响
→ 12学分拿到 → 本科到手 → 跳槽 → 月薪翻倍
→ 前期债务可还了 → 但青春也过了 → 新的焦虑出现
```

### 连锁链2：颜值投资路线

```
疯狂买护肤/医美 → charm大涨 → 酒吧搭讪触发 → 认识高质量男性
→ 但intellect不够 → 聊不下去 → "花瓶"
→ 继续投资颜值？还是转投学识？→ 精力有限只能选一个
→ 永远在权衡
```

### 连锁链3：社交孤立

```
删了小雅 → 没有女性闺蜜 → 遇到渣男没人提醒 → 容易被沈逸收割
→ 被骗后sanity暴跌 → 更不想社交 → 最终微信只剩家庭群
→ 家庭群也在催 → 全面崩溃 or 回家
```

## 十二、实现架构

### 数据驱动设计

NPC、微事件、春节话题等全部用JSON数据文件，不硬编码。
加NPC = 往池子里加卡片，不改核心逻辑。

### 实现优先级

```
Phase 1：核心系统
1. GameManager age>=35 改为 33
2. 春节BOSS战系统
3. 职场微事件系统
4. 数值门槛补全（酒吧/滑动交友/面试加门槛）

Phase 2：NPC系统
5. 小雅NPC（日常聊天+借钱+人生线）
6. 阿伟NPC（城中村房东儿子）
7. 陈默NPC（高端局男性）
8. 林远NPC（普通好男人）
9. 阿强NPC（同乡男生）
10. 周姐/同事NPC
11. 创二代事件

Phase 3：结局系统
12. 33岁终局判定 + 回顾系统
13. 婚恋结局
14. 崩溃结局完善

Phase 4：触发矩阵
15. "你有X但没有Y"触发器
16. "行为记录"触发器
17. "缺失状态"触发器
18. "里程碑后果"触发器
```

### 新增NPC的扩展方式

```
1. 创建 npc_data_xxx.json
2. 定义：id, name, title, trigger_conditions, daily_chats, milestones, events
3. 放入 Data/ 目录
4. 游戏自动加载，根据trigger_conditions决定是否出现
5. 不需要改任何核心代码
```

- [x] 游戏灵魂：数值互相卡脖子，不是剧本

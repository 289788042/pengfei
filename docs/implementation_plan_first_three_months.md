# 《错位时卡》前三月纵切片实施规格 V0.1

## 目标

先开发前三月纵切片，不做完整十年内容，也不做完整六男线。

验收目标：

- 玩家理解手机是主界面。
- 玩家理解周末只有两个主日程。
- 玩家理解钱、精力、情绪、成长和关系会互相抢时间。
- 玩家经历至少两次月结，能看懂账单压力。
- 林凡、阿强、陈默都从生活压力中自然出现，不像攻略对象弹窗。
- 随机男 NPC 不打断新手生活节奏。

## 本阶段不做

- 不做完整 23-33 岁内容。
- 不做完整六男线。
- 不做沈逸正式线，只保留后续伏笔。
- 不做顾凛正式线，只保留远景伏笔。
- 不做随机偶遇扩展。
- 不做 F1 调试系统。
- 不重做微信 NPC 大剧情。
- 不急着深挖金丝雀完整线，只做陈默第一段。

## 周末日程系统

### 基础规则

每周有两个主日程：

- 周六日程。
- 周日日程。

消耗主日程：

- 加班。
- 夜校正式上课。
- 线下约会。
- 地图出门行动。
- 关系重要事件。
- 住房/家庭等重大生活事件。

不消耗主日程：

- 打开手机 App。
- 查看支付宝账单。
- 读普通微信。
- 看朋友圈。
- 看日记。
- 看地图预览。

### UI 表达

不要写“行动次数”。

推荐显示：

- 本周日程：周六空闲 / 周日空闲。
- 已安排：周六 加班 / 周日 海边散心。
- 操作按钮提示：消耗周六日程、消耗周日日程、本周线下关系邀约已安排。

### 防肝规则

- 每周最多一次普通加班。
- 疯狂加班或特殊事件可消耗两个日程。
- 每周最多一次正式夜校课。
- 同一周最多赴一个线下关系邀约。
- 休息行动消耗日程，但用于恢复情绪/精力。

## 随机男 NPC 入口

第一阶段先禁用所有随机男 NPC 邂逅入口。

需要禁用或绕开：

- 健身房随机男 NPC。
- 图书馆/书店随机男 NPC。
- 酒吧随机男 NPC。
- 地点首次访问自动刷核心男 NPC。

核心男角色改为确定性入口：

- 林凡：普通生活擦肩。
- 阿强：家庭群/父母介绍。
- 陈默：第三月客户饭局主线。
- 阿伟：第四月后住房系统。
- 沈逸：后续文化/精神空虚伏笔，不在前三月正式出现。
- 顾凛：远景伏笔，不进前三月系统。

## 前三月流程

### 第 1 月：活下来

目标：

- 教支付宝。
- 教高德。
- 教微信。
- 教加班会伤情绪。
- 教休息能救情绪。
- 教第一次月结。

第 1 周：

- 手机亮起。
- 只能先开支付宝。
- 关闭支付宝后开高德。
- 高德只开放公司加班。
- 加班后引导开微信看家人消息。
- 看完微信后引导去海边恢复情绪。

第 2 周：

- 显示周六/周日两个日程位。
- 允许玩家第一次自由安排周末。
- 可选：加班、海边/公园、宅家、夜校广告伏笔。
- 林凡只做一次生活擦肩，不正式加微信。

第 3 周：

- 家庭群提到老家男孩，也就是阿强伏笔。
- 玩家可敷衍、问两句、表示不想认识。
- 不强制加微信。

第 4 周：

- 第一次月结。
- 工资到账、房租、餐饮、花呗最低还款/滚息进入支付宝流水。
- 给月度反馈。

### 第 2 月：熟悉日常

目标：

- 巩固周末日程。
- 林凡第二次擦肩，逐渐变熟。
- 阿强继续家庭伏笔。
- 不正式开放陈默、阿伟、沈逸。

第 1 周：

- 林凡第二次小帮助。
- 玩家可以多聊两句，但不急着恋爱。

第 2 周：

- 普通周末日程深化。
- 夜校广告再次出现，但正式报名可延后。

第 3 周：

- 家庭群第二次提阿强。
- 如果玩家之前问过，妈妈发更多信息。
- 如果玩家之前拒绝，妈妈说“认识一下又不是马上结婚”。

第 4 周：

- 第二次月结。
- 日记/月总结反映玩家第 2 月倾向。

### 第 3 月：陈默进入

目标：

- 陈默作为职场主线人物出现。
- 陈默不是恋爱突然降临，而是职场低位和资源差距的结果。
- 阿强正式进入微信。

第 1 周：

- 老板通知下周客户饭局。
- 玩家可选择：
  - 加班准备资料：饭局更稳，情绪下降。
  - 不准备：保留休息，饭局更狼狈。
  - 找周姐/同事请教：消耗日程，获得提示。

第 2 周：

- 客户饭局主线。
- 老板甩锅。
- 陈默救场。
- 玩家选择：
  - 礼貌感谢，保持距离。
  - 主动加微信，说以后想请教。
  - 借机抱怨老板和工作太累。

第 3 周：

- 家庭群正式推阿强微信。
- 玩家可加、不加、先拖着。

第 4 周：

- 如果玩家加了陈默，陈默发工作相关轻联系。
- 如果没加，项目/老板/周姐保留陈默回流入口。
- 第 3 月月结根据饭局准备、陈默选择、阿强选择给反馈。

## 角色入口规格

### 林凡

定位：深圳普通真诚线。

前三月只做擦肩和熟悉，不做正式恋爱。

出现方式：

- 城中村楼道。
- 便利店。
- 雨天屋檐。
- 通勤路上。

体验关键词：

- 小帮助。
- 不评价。
- 不表演。
- 普通人互相托一下。

### 阿强

定位：老家退路线。

前三月通过家庭群出现。

入口：

- 妈妈/亲戚介绍。
- 熟人社会压力。

体验关键词：

- 父母关心和安排混在一起。
- 稳定、安全、但有被推着走的感觉。

### 陈默

定位：高阶资源安置线。

前三月只做初遇和轻联系。

入口：

- 第 3 月客户饭局。
- 老板甩锅。
- 陈默救场。

体验关键词：

- 他不是来恋爱的。
- 他先是一个懂规则、有资源、能救场的人。
- 玩家心动的不是钱，而是“终于有人能改变局面”。

## 验收清单

开发完成后必须实机跑前三月。

检查：

- 第 1 周教程是否清楚，不压对话框，不乱开 App。
- 周末日程是否易懂。
- 玩家是否知道哪些操作耗日程。
- 月结是否清楚解释钱为什么没了。
- 林凡出现是否自然。
- 阿强是否像家庭系统自然推来。
- 陈默出现是否建立在职场压力之后。
- 随机男 NPC 是否没有出现。
- 第 3 月结束时，玩家是否已经理解游戏核心循环。

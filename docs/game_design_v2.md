## 一、我们怎么走到这个设计的（对话背景）

### 原来的设计
游戏叫"深漂"，屏幕左右分栏：右边手机UI，左边galgame。
主角是女性，去健身房或者其他场合被男人搭讪，触发galgame恋爱剧情。
手机端已经做好了：微信、宝淘、团美、BOSS弯聘、贝壳找房、高德地图、日记本。
微信已经做成了3个tab（微信聊天/通讯录/朋友圈），能和NPC聊天、删除拉黑好友。

### 转折点
用户（开发者）提出了几个顾虑：
1. 女性玩家玩的是恋与制作人那种，要精美立绘和幻想恋爱，现实主义题材不吸引她们
2. 女性对文字敏感，但开发者不了解女性文学/小说，担心写不好
3. AI写不出好剧情

### 讨论过程
Claude提了3个方向：
- 方向1：都市生存喜剧（推荐）——不谈恋爱，写深漂名场面，黑色幽默吐槽风
- 方向2：反乙女元叙事——知道自己在玩乙女游戏但现实总是不对劲
- 方向3：群像生活剧——多角色交叉

用户选了方向1。

### 性别讨论
开发者最初担心写不好女性视角，问能不能换成男性。
Claude做了全面分析：
- 内容丰富度：女性视角场景更多（渣男/闺蜜攀比/职场霸凌/容貌焦虑/催婚），男性偏"闷"（经济压力/职场内卷）
- 市场传播：女性视角内容在小红书/抖音更容易爆（"月薪6000的一天"/"渣男语录"/"独居女生"）
- 竞品空白：目前没有"女性视角都市生存喜剧"，中国式家长做了男性童年视角
- 写作难度：不需要文学功底，需要网感，吐槽风AI也能帮写

**最终决定：女性主角。**

### 关键结论
> 游戏的灵魂不是"女性文学"，是"社畜吐槽"。性别只是场景的调味料，核心味道是生活共鸣。

## 二、核心定位

- **类型**：都市生存喜剧（生活模拟 + Galgame叙事）
- **主角**：女性，刚到深圳打拼的年轻人，兜里5000块
- **基调**：黑色幽默 + 吐槽风，不是文艺风
- **灵感参考**：中国式家长的共鸣感 + 互联网吐槽文化
- **卖点**：女性视角的都市生存，市场空白
- **目标平台**：手机/PC（Godot 4.6.2）

## 四、游戏循环（以周为单位）

每周分三个阶段：

### 阶段1：手机时间（玩家主动操作）
```
必做：
  团美 → 选本周伙食（影响💰和❤️）
  BOSS弯聘 → 找工作或查看在职状态

选做（每周选1-2个）：
  高德地图 → 选一个地方去（触发galgame场景的主入口）
	健身房 / 咖啡厅 / 酒吧 / 公园 / 商场 / 公司加班 / 回家躺平

  宝淘 → 买东西
  贝壳找房 → 换房/续租
  微信 → 找人聊天/看朋友圈
```

### 阶段2：Galgame场景（叙事+选择）
- 看对话 → 做选择 → 看结果
- 触发方式：去某地 / 微信聊天 / 随机事件 / 主线剧情节点

### 阶段3：周结算
```
扣除房租 → 扣除饭钱 → 结算工资 → 更新数值 → 写入日记 → 进入下一周
```

## 六、Galgame场景设计

### 场景数据结构
```
场景 = {
  背景: "健身房",
  人物: ["私教小哥"],
  对话序列: [
	{ 说话人: "旁白", 文本: "你走进健身房，一个私教立刻迎了上来" },
	{ 说话人: "私教", 文本: "姐，你第一次来吧？我帮你做个体测" },
	{ 说话人: "私教", 文本: "哇，你这个体脂率......有点高啊" },
	{ 说话人: "旁白", 文本: "你低头看了眼自己的BMI，19.2" },
	{
	  选项: [
		{ 文本: "行吧，测就测", 效果: "进入体测流程" },
		{ 文本: "不了谢谢，我自己练", 效果: "私教继续纠缠" },
		{ 文本: "你体脂率多少？我看你也不低", 效果: "私教尴尬离开" }
	  ]
	}
  ]
}
```

### 场景分类

**1. 地点事件（去某地触发，每地点3-5个不同事件）**

健身房：
- 私教推销办卡（搞笑名场面）
- 遇到健身帅哥搭讪
- 更衣室碰到奇葩
- 镜子前看到自己变化（连续去多次后触发）

咖啡厅：
- 一个人去被搭讪
- 点了杯38块拿铁心痛
- 遇到同样一个人的女孩变成朋友
- 前任带新对象走进来

酒吧：
- 被请喝酒
- 遇到话痨
- 喝多了第二天头痛扣❤️

公园：
- 遛狗帅哥
- 广场舞大妈拉你加入
- 发呆遇到聊天的陌生人

商场：
- 被导购缠住
- 闺蜜约逛街攀比
- 看到打折忍不住剁手

公司加班：
- 老板画饼
- 同事摸鱼你干活
- 深夜独自在公司

回家躺平：
- 不触发场景，但恢复🧠心态

**2. 微信触发事件**
- NPC约见面 → 去不去？→ 去了触发galgame场景
- 闺蜜发消息"姐妹我被渣男了" → 怎么回？
- 老板深夜让你改方案 → 回还是装睡？
- 相亲对象发消息 → 聊什么？

**3. 随机事件（每周概率触发）**
- 房东突然涨租
- 半夜噪音
- 外卖送错了
- 下雨没带伞
- 公司群里老板@所有人

**4. 主线剧情（特定周数触发）**
- 第1周：刚到深圳，找房子找工作
- 第4周：第一次发工资
- 第8周：公司团建
- 第12周：过年回家还是留下？
- 第20周：升职/跳槽的关键时刻
- 第30周+：结局路线分化

## 七、NPC系统

| NPC | 身份 | 作用 | 对话风格 |
|-----|------|------|----------|
| **小雅** | 闺蜜/同事 | 日常吐槽搭子，有时攀比有时真心帮你 | "姐妹你看我新包" / "那个男的别理他" |
| **王老师** | 公司领导 | 职场线核心，可能提拔也可能PUA | "小x啊，这个周末加个班" |
| **林浩** | 相亲对象/暧昧男 | 感情线，前期表现完美后期逐渐暴露（可能是渣男） | 前期体贴，后期冷淡/已读不回 |
| **阿杰** | 健身房私教 | 搞笑担当，永远在推销 | "哥你这个体脂率有点高啊" |
| **房东张姐** | 房东 | 生活压力来源 | 涨租/催租/突击检查 |
| **妈妈** | 老家亲人 | 催婚/关心/要钱 | "有对象了吗" "给家里打点钱" |

关键设计：每个NPC有好感度，但**不是好感度越高越好**——比如渣男前期好感度刷得很快。

## 八、数值系统

```
💰 金钱    起点：5000    每周扣房租+饭钱，工作进账工资
❤️ 健康   起点：70      食物+运动+事件影响，太低会生病（扣钱+跳过一周）
🧠 心态   起点：80      好事坏事影响，太低会崩溃（强行躺平一周）
💼 事业   起点：Lv.0    工作表现+选择影响，决定收入上限
```

**核心：数值互相冲突，没有完美选择**
- 加班赚钱 → 💰↑ 但 ❤️↓ 🧠↓
- 去健身房 → ❤️↑ 但这周少赚钱
- 陪闺蜜逛街 → 花💰 但🧠↑
- 忍着不消费 → 💰保持 但🧠慢慢↓

## 九、结局路线

```
第30周左右分化，根据数值判定：

💰高 + 💼高           → 女王结局："深圳买不起房，但我活得有尊严"
💰高 + 🧠低           → 卷王结局："银行卡数字好看，体检报告不好看"
❤️高 + 🧠高 + NPC好感高 → 感情结局（不同NPC不同结局）
🧠高 + 💰低           → 佛系结局："没什么钱，但每天睡到自然醒"
所有数值都低           → 寄了结局："妈，我回来了"
特定条件触发           → 隐藏结局（暴富/网红/回老家创业）
```

## 十、文字风格（最重要）

**不需要文学性，需要网感。** 吐槽风、扎心、好笑。

```
❌ 文艺版：
"月光洒在她微微颤抖的睫毛上，泪水像断了线的珠子滑落……"

✅ 吐槽版：
"深南大道的灯确实挺亮，
 亮到我看清了银行卡余额。
 还有312块。
 这个月还有11天。
 挺好的。"
```

```
❌ 文艺版：
"他微微一笑，温暖的目光让我心跳加速。"

✅ 吐槽版：
"健身房的销售又来了。
 '姐你体脂率有点高啊'
 我183，130斤。
 '办张卡吧，新会员首月只要299'
 我看了眼余额。
 '我再考虑考虑。'"
```

参考风格：微博段子、小红书吐槽帖、抖音文案。不是小说/文学。

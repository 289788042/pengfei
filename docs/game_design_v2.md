# 深漂生存喜剧 - 游戏设计文档 v2

> 2025-05-15 讨论确定的方向

## 核心定位
- 类型：都市生存喜剧（生活模拟 + Galgame叙事）
- 主角：女性，刚到深圳打拼的年轻人
- 基调：黑色幽默 + 吐槽风，不是文艺风
- 灵感参考：中国式家长的共鸣感 + 互联网吐槽文化
- 卖点：女性视角的都市生存，目前市场空白

## 画面布局
```
左边：Galgame场景（背景图 + NPC立绘 + 对话框 + 选项）
右边：手机（微信/宝淘/团美/BOSS弯聘/贝壳找房/高德地图/日记）
底部：状态栏（💰金钱 ❤️健康 🧠心态 💼事业Lv 📅第N周）
```

## 游戏循环（以周为单位）

### 阶段1：手机时间
玩家通过手机App做本周安排：
- 团美 → 选本周伙食（影响💰和❤️）
- BOSS弯聘 → 找工作/在职状态
- 高德地图 → **选择去哪里**（触发galgame场景的主要入口）
  - 健身房、咖啡厅、酒吧、公园、商场、公司加班、回家躺平
- 宝淘 → 购物消费
- 贝壳找房 → 租房/换房
- 微信 → 聊天/看朋友圈（触发NPC剧情线）

### 阶段2：Galgame场景
- 看对话 → 做选择 → 看结果
- 触发方式：去某地/微信聊天/随机事件/主线剧情节点

### 阶段3：周结算
- 扣房租、扣饭钱、结算工资
- 更新数值、写入日记
- 进入下一周

## Galgame场景分类

### 1. 地点事件（去某地触发，每地点3-5个不同事件）
健身房：私教推销办卡、遇到健身帅哥、更衣室奇葩、镜子前看到变化
咖啡厅：被搭讪、38块拿铁心痛、遇到同频女生变朋友、前任带新对象出现
酒吧：被请喝酒、遇到话痨、喝多了第二天头痛扣❤️
公园：遛狗帅哥、广场舞大妈拉你加入、发呆遇到聊天的陌生人
商场：被导购缠住、闺蜜约逛街攀比、看到打折忍不住剁手
公司加班：老板画饼、同事摸鱼你干活、深夜独自在公司

### 2. 微信触发事件
- NPC约见面 → 去不去？
- 闺蜜被渣男了 → 怎么回？
- 老板深夜让你改方案 → 回还是装睡？
- 相亲对象发消息

### 3. 随机事件（每周概率触发）
- 房东突然涨租、半夜噪音、外卖送错、下雨没伞、公司群老板@所有人

### 4. 主线剧情（特定周数触发）
- 第1周：刚到深圳
- 第4周：第一次发工资
- 第8周：公司团建
- 第12周：过年回家还是留下
- 第20周：升职/跳槽关键时刻
- 第30周+：结局分化

## 数值系统
- 💰 金钱（起点5000）：每周扣房租+饭钱，工作进账
- ❤️ 健康（起点70）：食物+运动+事件影响，太低生病跳过一周
- 🧠 心态（起点80）：好事坏事影响，太低崩溃强行躺平
- 💼 事业（起点Lv.0）：工作表现影响，决定收入上限

**核心设计：数值互相冲突**
- 加班→💰↑ ❤️↓ 🧠↓
- 健身→❤️↑ 但这周少赚钱
- 逛街→花💰 但🧠↑
- 不消费→💰保持 但🧠慢慢↓

## 结局路线
- 💰高+💼高 → 女王结局："深圳买不起房，但我活得有尊严"
- 💰高+🧠低 → 卷王结局："银行卡好看，体检报告不好看"
- ❤️高+🧠高+某NPC好感高 → 感情结局（不同NPC不同结果）
- 🧠高+💰低 → 佛系结局："没什么钱，但每天睡到自然醒"
- 全低 → 寄了结局："妈，我回来了"
- 特殊条件 → 隐藏结局（暴富/网红/回老家创业）

## 文字风格
不需要文学性，需要网感。吐槽风、扎心、好笑。

❌ "月光洒在她微微颤抖的睫毛上……"
✅ "深南大道的灯确实挺亮，亮到我看清了银行卡余额。还有312块。这个月还有11天。挺好的。"

## 1. 用户协作方式和质量标准

- 用户希望 Codex 是“总策划 + 主程序”，不要客套，不要泛泛而谈，要从游戏体验、BUG、系统架构、可玩性角度主动推进。
- 用户非常在意“自己验收”。做完 UI 和流程必须用 Godot MCP 截图/运行验证，不能只凭代码想象。
- 用户对“水”的容忍度低。策划输出不能只讲大词，要细到：先说哪句台词、哪个按钮亮、玩家点错时弹什么、关掉 App 后下一步是什么。
- 用户希望我们能引导他聊系统，而不是每一步都等他想破脑袋。
- 用户并不反感重构，反而担心小补丁越打越乱。若系统层级、教程状态、UI 焦点、地点流程已经反复出错，应主动提出并执行干净重构。
- 用户强调“这是一款女性向/女性视角游戏”，但不是单纯乙女恋爱，也不是教条教育游戏。必须理解中国大城市普通女性的真实压力、婚恋困境、阶层跃迁幻觉和情感拉扯。
- 用户希望游戏能像《女神异闻录5》那样通过长期日常节奏让玩家感受到一种生活，而不是急着把 NPC 当攻略副本弹出来。
- 用户曾担心模型“降智”和“策划很水”。后续回答必须有主策划的判断力：不要只列方案，要能说为什么、怎么落地、先做哪一刀。

## 2. 项目一句话定位

《错位时卡 / 错位时差》是手机 UI 驱动的都市女性生活模拟 + 叙事经营游戏。玩家扮演 23 岁刚到深圳的林小满，在低工资、城中村、花呗欠款、职场低位、家庭压力、学习成长、消费包装和婚恋关系里做取舍，慢慢走向不同人生结局。

它不是“发财游戏”，也不是“纯恋爱游戏”。它讲的是：一个普通女性以为工作、消费、学历、体面和更高级的男人能帮她上岸，但每条捷径都在索取代价。真正能让她活下去的，是清醒、自我建设，以及珍惜真诚关系的能力。

## 3. 核心类型拆解

- 都市女性生存模拟：钱、精力、情绪、住房、工作、债务和家庭压力是底盘。
- 手机 UI 叙事：支付宝、微信、高德地图、日记、BOSS 弯聘等 App 是系统入口，不是装饰。
- 周节奏生活模拟：工作日做生存选择，周末安排加班、出门、学习、关系事件和休息。
- Galgame 式关系推进：重要 NPC 通过微信、地图邀约、线下事件、朋友圈和日记逐步累积，而不是一次邂逅马上攻略。
- 结局反推系统：每个系统都要把玩家推向某类人生轨道，而不是孤立提供功能。

## 4. 核心主题和立意

- 普通女性来到一线城市后，想通过努力、学历、消费包装、恋爱资源和人脉完成阶层跃迁。
- 游戏承认“男人可能成为上位路径的一部分”，但要表达：男人不是万能，优质男人不等于真诚，高阶男性的恋爱和婚姻常常分离。
- 自己越优秀，能进入更优秀的场所，遇到更优秀的男人，但高阶关系也更复杂、更难把控。
- 看起来特别厉害的男人可能会恋爱、宠爱、提供资源，但不一定会结婚；他的婚姻也许已经被家庭、资产、阶层利益安排好。
- 阶层翻越很难。用关系换资源不是单纯“失败”，但一定有代价：自由、边界、自主性、职业路径、家庭和自我感都会被重塑。
- 真诚是最重要的主题之一。游戏要让玩家在见过虚荣、资源、控制、诱惑之后，重新理解那些看起来“不够厉害”但真正爱你、支持你的人。
- 游戏不设绝对胜利或失败。每个结局都应成立，都要说明“她为什么会这样活下去”。

## 5. 参考气质

- 参考《东京女子图鉴 / 东京女子启示录》的感觉：城市阶层地图、年龄时间线、恋爱对象变化、欲望升级和幻灭。
- 不能照搬日本都市女性结构，必须落回中国式语境：深圳、城中村、花呗、父母催婚、春节、县城/老家、学历焦虑、互联网/服务业职场、客户饭局、租房和户口/买房压力。
- 参考 P5 的体验：通过日常、日程、关系、城市地点和慢节奏重复，让玩家真的“活在里面”。不要毛躁，不要让 NPC 一上来像功能按钮。

## 6. 主角和基础设定

- 主角：林小满，女性，23 岁，大专/低学历起点，刚到深圳。
- 初始居住：城中村/隔断间，资源紧、环境差、雨声和房间氛围要能压住人。
- 初始财务：现金约 3000，花呗已有欠款。开场台词提到欠钱时，支付宝内也必须真实显示，早期确认数字是 2876.32 左右。
- 初始目标不是恋爱、发财、逆袭，而是：先撑到下个月。
- 第一月不应展开复杂 NPC 支线、消费诱惑、求职跳槽和相亲恋爱。玩家刚开始要先学会呼吸。

## 7. 时间长度和节奏

- 用户曾预估 23 岁到 33 岁约十年，但不确定最终时长。
- 当前结构：一个月四周，一年 48 次周末。如果做满 10 年会非常巨大，必须谨慎控制体量。
- 用户喜欢“每周”的生活体验感，但担心玩家无脑肝：一直上课、一直加班、刷数值。
- 当前方向：保留周节奏，但重新引入“主日程/社交时间约束”，不是回到旧的硬行动次数。
- 查看手机、看账单、读微信、看地图预览、看日记不消耗主日程。
- 加班、上课、约会、出门、重要关系事件、健身、兼职等消耗主日程。
- 高强度事件可消耗更多日程或造成显著负面，例如连续加班导致过劳风险。
- 有些周可以很短：打工后今天就过了。不是每周都要塞满剧情。
- 关键事件可以像 P5 一样占用日程或自动推进，不必每次都让玩家自由选套餐。

## 8. 当前新手教程口径

第一周教程是强引导，目标是让玩家学会四件事：支付宝看钱，高德地图出门，加班换钱但伤情绪，微信和海边能提供人际/情绪支撑。

已确认顺序：

1. 开场旁白/对话告诉玩家先打开支付宝，再打开高德地图。
2. 对话说完后右侧手机应大大方方亮起来，可以操作。
3. 支付宝 App 图标呼吸发光，提示玩家点击。不能黄不拉几看不出来，也不能放大过头导致字看不见。
4. 点其他 App 时拦截，galgame 对话提示：“先打开支服了宝，看看账单吧。”
5. 点开支付宝后用小提示框解释，不要三层 UI 压在一起。提示框要放左侧空位，不要挡住现金/花呗数字；文字要换行，不要把框拉到最左边偷懒。
6. 关闭支付宝后，高德地图图标发光提示。
7. 打开地图后，公司加班置顶且唯一可做/重点可做，“宅家刷手机”锁住，因为台词已经说拿包出门。
8. 高德中“去加班/公司加班”卡片有呼吸发光，引导点击。
9. 对话可说：“先去加班吧，加班费可能会让我挺过这个月。”其中“加班”标黄。
10. 加班回来后，不要戛然而止，要引导打开微信：“打开微信看看，可能会发现家人和朋友的信息，不要错过他们。”
11. 微信图标像之前支付宝/地图一样发光放大，点击其他 App 提示先看微信。
12. 点开微信后自由探索，但必须出现家人关心事件：刚来深圳，家人很担心，结算情绪 +8。
13. 夜校王老师/尚德老师要发课程推销/介绍消息。
14. 玩家关掉微信后，地图解锁海边，同时加班锁住，只能去海边。
15. 在去海边前先讲情绪和数值系统：加班回来，精神紧绷，很疲惫，有些 emo；可以去海边散散心。
16. 蓝色教程文字说明：加班会减少情绪值，数值过低会导致严重后果；在快节奏城市里要照顾心理健康；自己的属性数值在右侧手机数值面板里看。
17. “手机里正在发光的那个框框就是”这句话弹出时，右侧数值面板才开始呼吸闪烁。之前没提到面板时不要提前闪。
18. 蓝色教程没点完时，右侧 UI 面板应一直呼吸；蓝字点完再停止，不是只闪两下就灭。
19. 蓝字结束后再说：“都了解的话，可以出发去海边散心啦。”地图再发光提示。
20. 海边回来后继续引导“结束本周”，不要让玩家不知道干嘛。
21. 第二周周末如果无指示，要提示：“地图里有新地点解锁了，可以打开看看。”

被用户否掉/修正过的台词：

- “再决定周末把自己带去哪里”不自然，应改为“再决定出门去哪”。
- “别被第一张账单退出去”不对，应为“别被第一张账单给劝退回老家了”。
- 重要剧情顺序：先说加班回来精神紧绷/疲惫/emo，再出蓝色教程，再说去海边散心和打开地图。

## 9. 支付宝体验口径

- 支付宝是第一月必须开的财务教学 App，但不能像真实财务系统那样一打开就把玩家劝退。
- 早期总览要简单、字号更大、重点突出。
- 开场如果台词说花呗欠钱，实际支付宝里必须显示对应欠款，约 2876.32。数字应加粗并偏黄/醒目。
- 初始总览里不要显示太多字：近三笔流水、本月最大支出、现金流拆解先隐藏，后续再开放。
- Tabs 顺序：总览、账单、花呗、理财。
- “关于”栏删除。
- “理财”暂时锁住，灰色，不能点。
- 总览提示框文案：这里显示你的资产状况。你手里的现金，花呗，和月底预估会剩的钱。
- 花呗提示框文案：这里会显示花呗的数额、还款/分期等详情。
- 账单提示框文案：这里会显示你的消费记录，包括下月房租等财务详情。
- 提示框不能盖住右侧主要数字。左侧空间大，就放左边。
- 支付宝打开后不能压住 galgame 对话框导致看不见。若不可避免叠 UI，底层 App 应降亮，最前面的对话框必须是视觉焦点。

## 10. 高德地图体验口径

- 高德地图已经决定回归手机小屏。以前做过大屏，但用户觉得不适合当前阶段。
- 地图负责周末行动入口，但第一月必须渐进开放，不要一开始一堆地点。
- UI 不要用单个字标签如“练”“园”，用户认为很 low。可用颜色、图标、锁、亮度状态表达。
- 不要写“可前往”“去”这种冗余按钮文案。可去就亮着，不可去就灰色锁住。
- 地图里很多地点一开始应灰掉/锁住；新手阶段先教核心循环。
- 第一周：公司加班打开并置顶；宅家刷手机锁住；海边在微信后解锁；加班后锁住，只引导海边。
- 第二周：提示地图有新地点，逐步解锁公园/图书馆等。
- 地图文字曾被用户指出太小、可读性差，后续所有地图卡片要优先读得清楚。
- 地点卡整张可点击。
- 地点卡应显示当前位置、精力/现金/花呗、地点消耗/收益/条件，但早期不要压成密密麻麻。
- 去海边/换地点时画面也要渐隐渐出，和音频同步，不能家里淡出但海边突然跳出来。

## 11. 微信体验口径

- 微信是第一月第三个教学 App。它的第一作用不是恋爱，而是让玩家意识到：手机里还有人，人际关系也是成本和支撑。
- 第一次加班后必须引导打开微信。
- 微信图标发光时，如果玩家按键盘返回/鼠标右键/点击返回都应被识别为完成探索。之前只有鼠标点返回才进入下一步，是 BUG。
- 在聊天页按右键不应该直接关闭微信；应返回微信主菜单/上一级。只有在微信主菜单时再右键，才关闭微信。
- 相亲相爱一家人里要有强制新手事件：刚来深圳，大家很关心，父母更担心，结算情绪 +8。
- 尚德夜校/王老师要发课程介绍/推销消息，作为后续上课/学历系统伏笔。
- 后期微信是关系系统主场，尤其是陈默线；但当前不急着深挖 NPC 剧情，因为用户多次说微信 NPC 剧情可能后面重做。

## 12. 日记、BOSS 和其他 App

- 日记是复盘工具，应记录本周/本月发生了什么、数值为什么变。
- 日记 App 出现时不能和 BOSS 弯聘同时无说明地出现。之前用户指出日记出来 BOSS 也同时出来，没有介绍，不对。
- BOSS 弯聘早期先隐藏。开局只保留高德地图、支付宝、微信。
- BOSS 可以放到更后面，等玩家理解生存循环后再介绍工作/跳槽。
- 支付宝、微信、日记属于信息密度大 App，可以做大屏；高德已经回归小屏；其他轻操作 App 可继续手机内。
- 未解锁 App 应隐藏或明确锁住，不能像坏按钮一样占格又挤乱图标位置。

## 13. 画面、音频和氛围

- 开场在家应有雨声。用户明确问过“我打开游戏 在家 为什么没雨声 开场那个场景 应该有雨声”。
- 音频文件夹有 Rain、Beach、Restaurant、Office 背景音。
- Rain 文件夹里的 `rain_on_window` 应用于下雨室内背景。当前只有健身房有不同天气背景，如果健身房背景是雨天，必须配套雨声，并区分大小雨。
- 切换场景时视觉和音频都应渐隐渐出。不能画面突然变、音频慢慢出来。
- 海边有背景图，用户说目录里有海边背景图，可以给公园/海边路线使用。加班美术素材暂时没有，先搁置。
- 层级原则：如果前面有对话，底层微信/支付宝/地图亮度压低，把玩家注意力集中到最前面对话。对话点掉后第二层再亮起。

## 14. 当前已确认结局池

旧文档和讨论里已有的结局不能丢。数值条件可以重定，但结局资产要保留。

存活/生存/崩溃类：

- 福报的代价：长期加班，用身体和情绪换钱。
- 过劳猝死/过劳崩溃：连续加班到危险阈值后的极端结局。
- 社会性死亡：微信只剩公众号和支付通知，人际关系全断且情绪崩。
- 老赖/债务崩溃：花呗/借贷滚到不可逆。
- 回老家/妈我回来了：撑不住深圳生活，离开城市。

成长/职业类：

- 深圳女王 / 清醒的孤岛：职业和钱赢了，但关系和情感代价很大。不是低级失败，是高位 BE。
- 学霸/知识改变命运：通过学历和长期自我建设进入新职业路径。
- 社畜结局：工作稳定但生活被吞。
- 网红结局/被关注的代价：外貌和流量带来上升，也带来被消费。
- 回老家创业 / 小城女强人：重要隐藏候选。不是简单失败，要重新定义商业真实感、和解意味和触发条件。

婚恋类：

- 真爱 / 难得的平凡：不一定只绑定“真诚男”，但林凡/真诚关系是代表路径之一。玩家抵抗虚荣和攀附，选择共同成长。
- 林凡/真诚男早期稳定线：如果玩家一开始愿意和林凡好，可以较快进入稳定结局或准结局。
- 金丝雀：陈默线代表。不是“傍大款失败”，而是用自由换稳定，被安置、被供养、被限制、被阶层关系收编。
- 恋爱脑的代价：长期用取悦换安全感，最后失去自我。
- 错过的缘分：不是惩罚没选男人，而是审判“当时看不起真诚，后来才懂”的时间代价。
- 阿强回老家：低门槛、很现实、容易进入，但本质是离开深圳，回到熟人社会和老家秩序。
- 金丝雀不是必须到 33 岁才触发。中途只要关系结构、依赖和控制积累到位，就可以进入“金丝雀状态”甚至中途结局。

强制年龄结算：

- 33 岁或 35 岁作为人生清算点仍可保留，但不要让所有结局都等到最后。婚恋、回老家、金丝雀都可以中途进入。

## 15. 恋爱系统总原则

- 恋爱系统不是男角色收集，而是人生路径选择。
- 玩家表面在回微信、赴约、问关系；系统背后记录她把时间、情绪、钱、身体、职业路径交给了谁。
- 关系推进要慢，要有日常、微信、朋友圈、线下事件、错过、冷却、挽留和现实压力。
- 不能让 NPC 像攻略对象弹窗。尤其前期，玩家已经要学习账单、地图、加班、情绪和手机 App，NPC 必须自然融入。
- 随机健身房/书店/酒吧搭讪先暂缓或删除早期入口。用户明确说健身房偶遇、沈逸等先全部别慌出来。
- 核心男性应按主线/生活结构进入，不是纯随机偶遇。
- 六个男生讨论过，但当前优先聊和落地：林凡、陈默、阿强、阿伟/城中村王子，以及后续高阶/文艺/消费型男性。具体名单可调整，但关系结构不能丢。
- 好感度是玩家可见的主轴，用于解锁聊天、线下约会、询问关系、确认关系、结婚/同居/分手等。
- 关键隐藏变量不要直接给玩家看，尤其陈默线。玩家只看到关系表象和好感，系统背后记录依赖和控制。
- 多人关系要冲突：时间冲突、微信冷落、朋友圈信息差、邀约撞期、关系清晰度要求、承诺收束。
- 当玩家进入某种承诺，系统需要提示人生方向正在收束，例如“你隐约感觉，自己正在把越来越多周末交给这段关系。”

## 16. 林凡

定位：深圳普通真诚线，不是霸总，不是救赎神。他是同样在城市里挣扎的人，给稳定情绪价值和真实生活支点。

关键词：

- 普通、真诚、稳定、一起成长。
- 不会说漂亮话，不提供巨额资源，但能在主角崩溃时接住她。
- 低幻觉、低控制、低资源上限。
- 他的价值要在玩家见过沈逸/陈默/消费诱惑后才更明显。
- 可以早期进入稳定线或准结局，用户明确说一开始的林凡如果愿意和他好，也会很快进入一种结局。

落地节奏：

- 第 1 月只做擦肩，不正式恋爱。
- 可在便利店、楼道、海边、公司附近等普通生活场景出现。
- 不要强制加微信，不要像攻略对象弹窗。
- 日记可以留下“楼下那个男生好像住在附近”之类轻痕迹。
- 第 2 月第二次出现，做小帮助，让普通关系自然变熟。

## 17. 阿强与阿伟/城中村王子

用户后来要求加“城中村房东儿子/城中村王子”，而且问阿强和林凡有什么区别。

当前需要区分三个结构：

- 林凡：普通深圳打工真诚男，代表共同成长和情绪支撑。
- 阿强：老家/父母/同乡系统推来的男生，代表熟人社会、回老家、低风险退路。
- 阿伟/城中村王子：本地城中村资源结构，代表嫁入本地房产/收租/家族秩序。

阿强：

- 通过家庭群/父母介绍自然进入，不是随机搭讪。
- 跟玩家老家有连接，父母更容易认可。
- 现实、善良、门槛低，但终点常常是回老家或回到熟人社会。
- 选择阿强不是失败，是一种生活路径，但它会收束深圳上升空间。

阿伟/城中村王子：

- 城中村房东儿子/本地资源男，不明说潮汕，但可有本地家族、传统、妈宝、家族规矩、房产/收租等气质。
- 日常接触应来自城中村生活：修水龙头、楼下碰面、房租/安全/邻里。
- 他不是林凡。林凡给情感平等，阿伟给生活资源和本地秩序。
- 他的诱惑是“住的问题一下被解决了”，代价是进入传统大家庭和本地规则。

## 18. 陈默 / 金丝雀线

陈默是主线级 NPC，不应作为随机书店/健身房/酒吧偶遇出现。用户明确提出：他必须在玩家刚开始没多久、还贫穷、处于职场低位时，作为设定好的主线人物出现才合理。

当前最新设定：

- 陈默采用“离异有孩子型”高阶男性。
- 他不是传统油腻坏人，也不一定是在骗女主。他可以真喜欢林小满，也能给钱、资源、工作机会和情绪稳定。
- 他的危险不在于暴力或纯欺骗，而在于“他真的觉得自己在对你好”。他默认资源交换会带来安排权。
- 林小满进入他的生活后，不是平等伴侣，而是被安置在一个舒适但不完整的位置上。
- 金丝雀不是“傍大款失败”，而是“用自由换稳定”。结局不应骂玩家，要让玩家感觉：这也是一种上岸，但船不是她掌舵。

首次登场：

- 定为商务饭局/客户局，而不是高端商场、书店、酒吧或健身房偶遇。
- 他先以客户/资源方出现，不直接以恋爱对象出现。
- 让工作系统和恋爱系统第一次强耦合。
- 玩家应已被房租、加班、低工资、老板甩锅和职场低位磨过几轮。
- 陈默第一次甜头是“先救工作危机，再给赚钱机会”。
- 场景可为老板甩锅，陈默淡淡说一句，把问题重新归回老板和项目机制，让林小满免于难堪。
- 后续通过微信或客户渠道给资料兼职、项目奖金、体面工作入口。

玩家回应陈默救场的三种心理：

- 礼貌感谢但保持边界：自主性上升，陈默好感小幅上升。
- 主动加微信请教：陈默好感上升，陈默线正式开启；玩家以为抓住的是职业机会。
- 抱怨工作/暴露脆弱：情绪恢复，陈默好感上升，控制度也上升；陈默更容易用“我是在帮你”介入。

陈默隐藏变量：

- 控制度
- 自主性
- 关系清晰度
- 钱依赖
- 房子依赖
- 工作依赖
- 退出倾向
- 金丝雀状态

用户明确要求：这些变量玩家看不到，只能看到好感度。好感度用于限制线下约会、询问关系、确立关系、结婚/同居/摊牌等。隐藏变量用于判定走向金丝雀、清醒退出、长期模糊、资源依赖或极稀有关系谈判。

陈默资源阶梯：

- 轻资料兼职/介绍项目：钱入账，代价轻，开始进入私人时间。
- 商务饭局/客户局：收益更高，陈默开始决定她去哪张桌、见什么人、穿什么合适。
- 工作机会/住处安排：职业路径和居住空间被陈默影响，控制感最强。

陈默越界递进：

- 穿着控制：今晚穿素一点/别太学生气/那个颜色不适合这个局。
- 职业汇报关系控制：以后这类事情先跟我说。
- 居住空间控制：这么晚回城中村不安全，今晚先住我那边的客房。

孩子和前妻：

- 不在第一次登场直接暴露。
- 在玩家已经接受过几次资源、相信他是贵人之后逐步出现。
- 例如聊天、吃饭、坐车时手机弹出孩子消息，陈默轻描淡写解释。
- 这会让玩家第一次意识到：他的人生已经有前妻、孩子、资产安排和家庭边界。

金丝雀状态：

- 第一次满足条件时，不要立刻弹结局。先进入“金丝雀状态”。
- 状态中陈默会干预部分行动：上夜校、见朋友、加班、问关系。
- 例如玩家要上夜校，陈默劝“别把自己逼这么紧”；玩家要见朋友，他说“那种圈子少回去”；玩家要加班，他说“你没必要挣这种辛苦钱”；玩家问关系，他温柔回避。
- 如果玩家连续接受干预，进入金丝雀中途结局。
- 如果多次拒绝干预，可以清醒退出，代价是失去资源、情绪下跌、现实压力回潮。
- 清醒退出也需要纠缠入口、陈默挽留和玩家挣扎，不能一键分手。

陈默落地闭环第一版：

- 第 2/3 月客户饭局认识陈默。
- 微信收到资料兼职。
- 支付宝看到“陈默介绍项目辛苦费/资源入账”。
- 地图出现咖啡厅交资料/饭局关系邀约卡。
- 饭局里被建议穿着。
- 朋友圈看到孩子/阶层信息。
- 玩家第一次问关系或保持沉默。

## 24. 记忆更新规则：什么时候算阶段结束

“阶段结束”不按自然时间算，也不按一次聊天算。只要出现下面任一情况，就算一个需要同步记忆的小阶段结束：

- 用户明确拍板一个设计方向，例如“地图回小屏”“陈默必须主线出现”“随机偶遇先删”“按你的来”。
- 一个功能从设计到代码实现，并且至少通过一次运行/截图/脚本验证。
- 一个反复 BUG 找到根因并修完，例如地图透明、套餐按钮灰、微信右键关闭、海边切图突兀。
- 一次较大的架构调整完成，例如抽出 TutorialDirector、PhoneAppController、UIFocusManager、LocationActionRunner。
- 用户明确推翻旧口径，例如“不要大屏地图”“不要随机沈逸”“不是失败，都是结局”。
- 提交 commit 或 push GitHub 前后。
- 对话进入新主题前，例如从新手教程转到恋爱系统，从恋爱系统转到音频和场景切换。
- 上下文明显变长、可能丢细节时，必须先做记忆同步。

更新时机：

- 设计讨论当场确定后，更新 `PROJECT_MEMORY.md`。
- 代码实现和验证完成后，更新 `DEV_MEMORY.md`。
- 如果用户只是在抛想法、还没拍板，用“候选/待讨论”标注，不能写成已定。
- 如果旧设定被废掉，不直接抹掉，要写清“旧口径”和“最新口径”，避免以后又被旧文档拉回去。
- 如果是细节台词、UI 指示、数值、按钮顺序，只要影响玩家体验，也要写。这个项目不能只记大方向。

记忆状态标签：

- 已定：用户明确认可，或已实现并通过验证。
- 候选：方向可用，但还没拍板。
- 待验证：代码已改或设计已定，但还没跑完整体验。
- 废弃：明确不要再沿用，例如早期随机男 NPC 打断新手、地图大屏、开局显示 BOSS。
- 历史资产：现在不做，但不能丢，例如金丝雀、回老家创业、春节系统、林凡旧线。

## 26. 以后继续补记忆时的写法标准

- 不能只写“优化支付宝教程”，要写用户为什么不满、原问题是什么、最终口径是什么。
- 不能只写“陈默是高阶男性”，要写他为什么不是随机偶遇、为什么是客户饭局、为什么危险来自“我是在对你好”。
- 不能只写“微信第一周引导”，要写打开微信前后 App 高亮、点错提示、右键返回、家人情绪 +8。
- 不能只写“修 UI 层级”，要写哪几层叠了、谁应该压暗、谁是焦点。
- 不能把候选当已定。比如 33 岁/35 岁、十年体量、六个男生具体名单，仍有可调整空间。
- 不能因为旧代码里有随机邂逅，就让它重新进入新手阶段。最新口径是随机偶遇暂缓。
- 每次最终回答前，如果本轮产生了长期设计或技术结论，应主动问自己：要不要写回 `PROJECT_MEMORY.md` 或 `DEV_MEMORY.md`。
